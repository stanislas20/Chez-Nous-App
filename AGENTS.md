# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

## iOS push: `aps-environment` is set to `development`

`ios/` is generated by prebuild and gitignored, so the entitlement lives in
`app.json` under `ios.entitlements` — editing `ChezNous.entitlements` by hand is
wiped on the next build.

It is set to `development`, which is correct for `expo run:ios` onto a device
signed with a development profile. **An App Store or TestFlight build needs
`production`.** Ship it as `development` and every push silently fails for real
users: the token is issued against Apple's sandbox and the live APNs gateway
does not know it. There is nothing in the build output that says so.

When a release pipeline exists, this should be driven by the build profile
rather than left as a constant.
